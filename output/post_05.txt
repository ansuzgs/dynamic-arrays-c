  Demo 1: Macro API vs Raw void* API (side by side)
═══════════════════════════════════════════════════════════════════

  --- The old way (Post 4): raw void* ---

    Array *arr = array_create(sizeof(int), 4);
    int x = 42;
    array_push(arr, &x);                    // verbose
    int *val = (int *)array_get(arr, 0);    // unsafe cast
    result: 42

  --- The new way (Post 5): type-safe macros ---

    Array *arr = ARRAY_CREATE(int, 4);
    ARRAY_PUSH(arr, int, 42);               // one expression
    int *val = ARRAY_GET(arr, int, 0);       // typed pointer
    result: 42

  ARRAY_FOREACH(arr, int, val) { sum += *val; }
  expands to:
    for (size_t _i = 0; _i < arr->size; _i++)
      for (int *val = (int*)element_at(arr, _i); val; val=NULL)
        { sum += *val; }

  Demo 5: What the preprocessor actually generates
═══════════════════════════════════════════════════════════════════

  Source code:
    ARRAY_PUSH(arr, int, 42);

  After preprocessing (conceptual):
    do {
        if (sizeof(int) != (arr)->element_size) {
            fprintf(stderr, "ARRAY_PUSH: type size mismatch (sizeof(int)=4, element_size=%zu)\n",
                    (arr)->element_size);
        } else {
            int _push_tmp = (42);
            array_push((arr), &_push_tmp);
        }
    } while (0);

  Key observations:
    1. do { } while(0) makes the macro a single statement
    2. sizeof(int) is computed at COMPILE time (always 4)
    3. arr->element_size is checked at RUNTIME
    4. int _push_tmp = 42; lets the compiler type-check the assignment
    5. &_push_tmp is passed to void* array_push — type erased
    6. #type stringifies the type name for error messages

  Source code:
    int *val = ARRAY_GET(arr, int, 0);

  After preprocessing (conceptual):
    int *val = ( sizeof(int) != (arr)->element_size
                 ? ( fprintf(stderr, "..."), (int *)NULL )
                 : (int *)array_get((arr), (0)) );

  Key observations:
    1. ARRAY_GET is an EXPRESSION, not a statement (returns a value)
    2. Ternary operator: check first, then either error or cast
    3. Comma operator: print error AND return NULL
    4. The cast (int*) provides typed access — no manual cast

  Knowledge Test
═══════════════════════════════════════════════════════════════════

  Q: Write a macro ARRAY_GET(arr, type, index) that returns
     a typed pointer. What happens if the user passes the
     wrong type?

  A: #define ARRAY_GET(arr, type, index)                  \
       ( sizeof(type) != (arr)->element_size              \
         ? ( fprintf(stderr, "type mismatch"), (type*)NULL ) \
         : (type *)array_get((arr), (index)) )

     If the user passes the wrong type:
     - sizeof(wrong_type) != arr->element_size
     - The ternary takes the error branch
     - An error is printed with the mismatched sizes
     - NULL is returned (not a corrupted pointer)
     - The array data is never accessed with the wrong type

     What it CANNOT catch:
     - Types with the same sizeof (int vs float on most
       platforms, both 4 bytes). The size check passes,
       but the bytes are interpreted differently.
     - This is a fundamental limitation of size-only checking.
       For same-size type safety, you'd need typeof() (GCC)
       or _Generic (C11) — discussed in the tradeoffs section.
